# Physical-disk cube-folding manuscript and proof package

This package presents a computer-assisted proof that a physical square-grid disk with a surjective consistent complete-frame cube map admits a valid layered PL folding on the unchanged source. It includes a self-contained manuscript, its complete finite certificates, reproducible verification, an explicit smaller example, and a theorem-level prior-art comparison.

**Addition of 9 November 2026 (evening): Corollary A2.** Section 5, now titled "Proof of the main theorem and its corollaries", ends with **Corollary A2**: whether a simply connected polyomino with \(N\) squares folds onto the cube can be decided in \(O(N^7)\) time, and simple connectivity in \(O(N)\) time. This settles the simply connected case of [ALL25, Conjecture 4.10]; the conjecture remains open for polyominoes with holes. The candidate crease arcs, the *cuts*, are the maximal straight runs of retained joins through full stars, and they depend only on the source. Every noncrossing set of cuts is the bend set of exactly one consistent map with a given root frame. By Lemma R1 and Proposition C3, a disk that folds has a six-face map bending along at most seven cuts, so the algorithm enumerates noncrossing sets of five to seven cuts. Soundness uses Theorem L7, Theorem M3 and Corollary D1; completeness uses Proposition C3. So the corollary rests, like Theorem A, on the computer-checked finite claim C2. The tree case was already polynomial by the classification of [ALL25, Section 7], as [LS25] notes, and the Introduction credits this. The former unlabelled corollary of Section 5 is now Corollary A1. The Abstract gains one sentence, and the Introduction's paragraph on Open Problem 9.2 no longer says that Conjecture 4.10 is unsettled for disks. ## Run the proof checks

An ordinary Python 3.10+ installation suffices for the main finite certificate:

```sh
cd supplement
python3 -I -S check_integrity.py
python3 -I -S verify.py --output verification-new.json
```

Use a fresh output filename; existing files are protected. `-O` and `-OO` are explicitly rejected. The successful result must report 87,538 patterns, 80 small minima, 4,080 rejected cheaper assignments and nine rejected negative controls. It also reports 1,987,252 endpoint comparisons, two for each edge of each pattern. These, like the assertions of the selected active/inactive status, hold for every bit vector once the reflection table σ is correct, so they are consistency checks of that table, not evidence about the witnesses (Section 3.2). The substantive checks are exact equality of the certificate key set with the regenerated domain and, for each witness, its parent array, the Lemma C1 recurrence on all eight cube vertices, six-face coverage and at most seven active bits. Seven of the nine controls are semantic corruptions; the other two (`missing_high_arc_pattern` and `extra_out_of_domain_pattern`) only illustrate the set comparison and cannot fail. See the supplement README for the exact scope of these counts.

The construction in the proof of Lemma L2 (Section 4.2) has separate tests:

```sh
cd supplement/l2-bank-orders
python3 l2harness.py impl.py 3000 5501 40 a,b1,b2
python3 check_counterexample.py
python3 check_adversarial.py 5504 4
```

`supplement/l2-bank-orders/README.md` lists the remaining commands. These are tests of the construction, not a proof of the lemma.

The supplement proves the finite colored-tree claim. It does not by execution alone prove the analytic source reduction, layer assembly, topology, or novelty. Those obligations are addressed separately in the manuscript and review records. The broader rank-three/rank-four research claims are excluded from this package.

## Rebuild the manuscript

Build dependencies are separate from proof verification. In a fresh build environment install `pypandoc_binary==1.17` and `typst==0.15.2`, then run:

```sh
python build/build_manuscript.py
```

This assembles the sections, exports Markdown/LaTeX/Typst, and builds the PDF. `build/build-record.json` binds the section hashes and output hashes.
